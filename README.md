# Ocarina Digital — versión inicial

Submarca de Ocarina Producciones. Plataforma comercial local para San Patricio del Chañar.

## Estado de esta versión
Esta es una primera versión de la vidriera, no una tienda con cobros y entrega automática. Los productos son fichas de lanzamiento, no archivos finales descargables. Precios y enlaces de pago están vacíos deliberadamente.

## Configuración
Editar `js/config.js`: completar WhatsApp, productos, precios y enlaces de pago; activar anuncios y completar sus datos. Probar todos los enlaces antes de publicar.

## Publicación
Usar GitHub como repositorio y un hosting cuyo plan y términos permitan el uso comercial. No asumir que GitHub Pages es adecuado para alojar una tienda cuyo propósito principal sea comercial.

## Archivos
- `index.html`: estructura.
- `css/styles.css`: diseño adaptable.
- `js/config.js`: catálogo, anuncios y contacto.
- `js/app.js`: renderizado y comportamiento.

## Antes de vender
Preparar los productos descargables reales, definir precios, conectar y probar cobro/entrega, obtener autorización para marcas e imágenes de anunciantes y establecer condiciones de publicidad mensual.
